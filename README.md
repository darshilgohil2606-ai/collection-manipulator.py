# Student Data Organizer

## 1. Introduction
The Student Data Organizer is a simple Python-based project used to manage student information. It allows users to add, display, update, and delete student records. It also displays all subjects offered by the students.

## 2. Objectives
- To store and manage student information.
- To add new student records.
- To display all student details.
- To update student age and grade.
- To delete student records.
- To display the list of subjects offered.

## 3. Technologies Used
- **Programming Language:** Python
- **Data Structures:** List, Dictionary, Tuple, Set
- **Input/Output:** Console-based interface

## 4. Features
1. **Add Student:** Enter the student's ID, name, age, grade, date of birth, and subjects.
2. **Display All Students:** View the details of all students.
3. **Update Student Information:** Update a student's age and grade using their ID.
4. **Delete Student:** Remove a student record using their ID.
5. **Display Subjects Offered:** Display the unique subjects available in the student records.
6. **Exit:** Exit the program.

## 5. Data Structures Used
- **List:** Stores all student records.
- **Dictionary:** Stores each student's information.
- **Tuple:** Stores the student ID and date of birth.
- **Set:** Stores subjects without duplicate entries.

## 6. How to Run the Project
1. Install Python on your computer.
2. Copy the project code into a file named `student_data_organizer.py`.
3. Open the terminal or command prompt in the folder containing the file.
4. Run the following command:

   ```bash
   python student_data_organizer.py
   ```

5. Select an option from the menu.
6. Follow the instructions displayed on the screen.

## 8. Advantages
- Easy to use and understand.
- Helps organize student information.
- Supports basic record management operations.
- Demonstrates important Python data structures.
- Suitable for beginners learning Python programming.

## 9. Limitations
- Student records are stored temporarily in memory.
- All records are lost when the program exits.
- The program does not use a database or permanent file storage.
- Input validation is limited.

## 10. Future Scope

## 11. Conclusion
The Student Data Organizer is a beginner-friendly Python project that demonstrates how to manage student information using lists, dictionaries, tuples, and sets.
